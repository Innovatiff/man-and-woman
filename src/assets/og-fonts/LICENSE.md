# Fonts used for generated social share images

These fonts are used only at build time to render the site's Open Graph / social
share images (`/og/*.png`). They are not served to site visitors.

- **Lora** (Bold) — © Cyreal, licensed under the SIL Open Font License, Version 1.1.
- **Work Sans** (Regular) — © The Work Sans Project Authors, licensed under the SIL
  Open Font License, Version 1.1.
